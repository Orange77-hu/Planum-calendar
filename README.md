# Planum · 计划日历

一个用 **纯 Rust + egui** 写的桌面日历 / 待办应用：本地存储、深色主题、完整中文农历、周/月双视图、课表、窗口记忆、导入导出，无网络请求、无需登录。

</div>

---

## ✨ 功能

### 📅 月视图 / 周视图（一键切换）
- **月视图**：月历格子，农历 / 干支 / 生肖 / 节气 / 节日，跨月日期弱化，当日橙色圆角高亮，重点日星标 + 备注
- 月视图卡片把**日程 / 每日计划**画成语义色圆角小方块，**一个方块包裹一个关键词**（方块宽度随关键词自适应、文字居中在块内，一眼看清每天有哪些安排）；**阶段计划**在卡片底部用纯色小方块单独成区，两区之间有淡分隔线。悬停为整格轻抬 + 顶部居中的柔和圆角小条，不再有左侧光带或生硬横线，也不遮挡日期与内容
- **周视图**：一页一周，每天按**自定义时间段**切成卡片；课程与带时段的待办自动落入对应「周几 × 时间段」卡片，支持全天区；一周起点可在「周一起 / 周日起」间切换，星期与日期自动对应
- 有内容的时段卡片以圆角块高亮，可开启**方块颜色跟随日程 / 优先级色**
- 顶部 `月 / 周` 按钮切换；周视图 `‹ ›` 按周翻页，切换时自动定位到选中日期所在周

### 📚 课表（每周重复课程）
- 课程字段：名称 / 星期 / 起止时间 / 地点，按周几自动重复显示，落进周视图对应时段格
- **手动添加**：顶部 `课程` 按钮 → 表单录入，支持编辑 / 删除
- **JSON 导入**：`导入/导出` 面板 → `导入日程…`，选文件即导入；`AI 导入提示词…` 给出可复制的提示词，把课表文件（截图 / PDF / 照片）和提示词一起发给 AI，再把回复**整段粘进弹窗**点「粘贴并导入」即可——不用另存成文件，代码块和前后说明文字都能识别
- 课程也支持**语义关键词**：`日程` 表单里填 2~6 个字的短标签（如「高数」「模电」），月/周日历方块显示它；留空则显示课程全名
- JSON 格式：`{"courses":[{"name":"高等数学","weekday":1,"start":"08:00","end":"09:40","place":"A301","keyword":"高数","start_date":"2026-09-01","end_date":"2027-01-15"}]}`
  （`weekday`：0=周日 … 6=周六；也兼容 `day`：1=周一 … 7=周日；`keyword` / `place` 选填）

### ✅ 待办（每日任务）
- 每日详情**左右分栏**：左栏「每日计划」（按重要度排序，可在设置里改），右栏「每日日程表」（课程 + 带时段待办，按时间排序，可在设置里改）；课程行直接显示上课地点，悬停可看完整信息
- 支持**时间段**：添加栏 `起 – 止`（如 `08:00 – 09:40`），留空即全天任务；点旁边「选」可弹出面板，用「时 / 分 / 秒」三条滑块选择（24 小时制、零填充），也可直接手输；秒为 0 时仍写成 `HH:MM`
- 所有需要填日期 / 时间的地方（阶段计划起止、日期跳转、导入导出日期、日程生效日期与上课时间、周视图时间段）都配了点选按钮：日期可选年月日，时间可选时分秒，空值默认显示当前日期时间
- 新建计划可填**关键词**（选填，留空则卡片退回显示完整事项文字）；月/周日历卡片上的小方块显示关键词，右侧每日计划列表也会带上「关键词」标签，双击可改
- 添加栏回车保存后**输入框与焦点都保留**，可连续录入多条；点击别处自动收起输入框
- 优先级点击直接切换、单击选中高亮 / 双击就地编辑、`Enter` 与点击外部保存、`Esc` 取消
- 未来七天同样合并显示带时段待办

### 📋 左侧栏
- 今日大日期 / 实时时钟 / 一天时间进度
- 本月任务统计与完成率
- 阶段计划列表（创建 / 就地编辑 / 删除，整行悬停高亮，竖三点菜单）；新建表单带「取消」按钮，点表单外或按 Esc 也能取消
- 未来七天待办 + 阶段计划合并显示

### ⚙️ 设置面板
顶部 `设置` 按钮打开，集中管理：
- 皮肤：内置 9 套配色（曜夜 / 晨雾 / 森屿 / 霞光 / 深海 / 暖阳 / 星黛 / 青瓷 / 樱雾），支持白天 / 黑夜各选一套组成「一套皮肤」，模式可选跟随系统明暗、按时段（7:00–19:00 白天）或固定一套；跟随模式会随系统主题自动平滑换肤，设置面板点配色预览块即换，自动记住选择
- 控件打磨：按钮/输入框统一圆角与留白、极淡描边与悬停抬升反馈，浅色皮肤下文字与描边同步适配
- 日期选择面板：数字改为柔和圆角方片，字号加大对齐，悬停抬升 / 今天描边 / 选中实心，三种状态清晰可辨
- 排序规则：每日计划（重要度 / 时间）、每日日程表（时间 / 重要度）各自独立
- 周视图一周起点（周一起 / 周日起）、时段卡片颜色是否跟随日程
- JSON / Markdown 导入导出（范围日 / 周 / 月 / 年，原生文件选择器）
- 课表 JSON 导入 / AI 导入提示词 + 粘贴导入（复制提示词发给 AI，回复整段粘进来点「粘贴并导入」，不用另存文件）

### 🎛 其他
- 课程管理：顶部 `课程` 按钮手动添加 / 编辑 / 删除每周重复课程
- 时间段管理：顶部 `时段` 按钮自定义周视图时段卡片（数量 / 起止）
- 日期跳转：点击「跳转」按钮直接变输入框
- 窗口记忆：记住上次的位置 / 大小 / 最大化状态
- 主题：内置 9 套皮肤可一键切换（含四套浅色），可设白天/黑夜成套自动切换，系统原生标题栏用 DWM 随皮肤染色，选择自动保存
- 右键菜单、快捷键 `N` / `P` / `←` / `→` / `T` / `Esc` / `Enter`（编辑时自动屏蔽冲突键）

## 🛠 技术栈

| 项 | 说明 |
|---|---|
| 语言 | Rust 2021 |
| GUI | egui / eframe 0.29（persistence 持久化） |
| 农历 | 自研移植（1900–2100 数据表） |

| 序列化 | serde + serde_json |
| 原生文件对话框 | rfd 0.15 |

## 🚀 构建与运行

需要 Rust 工具链（Windows 下自动加载系统中文字体，并从 Segoe UI Symbol 取竖三点字形）。

```bash
cargo run                 # 开发模式
cargo build --release     # 优化版，产物 target/release/Planum.exe
```

预编译包：[Releases](https://github.com/Orange77-hu/Planum-calendar/releases)

## 📁 项目结构

```text
egui-version/
├── Cargo.toml / Cargo.lock
├── icon.ico
├── src/
│   ├── main.rs     # UI / 交互 / 周月视图 / 课程 / 动画 / 绘制
│   ├── data.rs     # 数据层：待办(含时段) / 课程 / 阶段计划 / 重点日 / 导入导出
│   ├── lunar.rs    # 农历 / 干支 / 节气 / 节日
│   └── icon.rgba   # 窗口图标 RGBA（编译期嵌入）
```

## ⌨️ 快捷键

| 键 | 功能 |
|---|---|
| `N` / `P` | 打开待办添加栏 / 新建阶段计划 |
| `←` / `→` | 上一月（周视图：上一周）/ 下一月（周视图：下一周）|
| `T` | 回到今天 |
| `Esc` | 收起面板 / 取消编辑 |
| `Enter` | 保存当前编辑 / 日期跳转 |
| 双击待办 | 就地编辑 |

> 编辑期间 `N` / `P` / 翻页快捷键暂时屏蔽，避免误触。

## 📝 数据说明

本地存储，无需账号、无网络请求。首次启动写入示例数据。

| 文件 | 位置 | 说明 |
|---|---|---|
| `calendar-data.json` | `%APPDATA%\DeskCalendarEgui\` | 待办 / 课程 / 时间段 / 阶段计划 / 排序偏好 等 |
| `app.ron` | 同上 | egui 持久化：窗口几何 `win_geom`、主题偏好（实际配色由所选皮肤决定） |
| `exports\` | 同上 | 导出文件默认目录 |

删除 `calendar-data.json` 即可恢复初始示例数据。

# Planum · 计划日历

一个用 **纯 Rust + egui** 写的桌面日历 / 待办应用，本地存储、深色主题、中文本地化。

</div>

---

## ✨ 功能

**日历**
- 月历视图，节气 / 农历 / 干支 / 生肖标注，跨月日期自动弱化
- 重点日星标，**可添加备注**（鼠标悬停星标即可查看）
- 每日上方角标显示当日待办数量，不与其他信息重叠
- 阶段计划在日期格底部以**居中的彩色小方块**标记，不遮挡两侧内容

**待办**
- 按日期查看当日待办，支持优先级（高 / 中 / 低）与完成状态
- **单击选中高亮、双击就地编辑**，回车保存、点击外部保存、Esc 取消
- 悬停高亮色跟随优先级，已完成项整体置灰

**左侧栏**
- 今日大日期 / 实时时钟 / 一天时间进度
- 本月任务统计与完成率
- 阶段计划列表（可创建 / 删除，整行悬停高亮）
- 未来七天待办（不限条数，日期粗体强调）

**交互**
- 右键菜单：添加待办 / 标记重点日 / 回到今天
- 键盘快捷键：`N` 添加待办、`P` 新建阶段计划、`←` `→` 切月、`T` 回到今天、`Esc` 收起
- 月份切换淡入动画、选中脉冲等微交互

**数据**
- 全部本地存储（JSON，位于 `%APPDATA%/DeskCalendarEgui/`）
- 无需登录、无网络请求、无账号

## 🛠 技术栈

| 项 | 说明 |
|---|---|
| 语言 | Rust 2021 |
| GUI | [egui](https://github.com/emilk/egui) / [eframe](https://github.com/emilk/egui/tree/master/crates/eframe) 0.29 |
| 农历 | 自研移植（1900–2100 数据表）|
| 序列化 | serde + serde_json |
| 依赖 | chrono、eframe、serde、serde_json（仅此四个）|

## 🚀 构建与运行

需要 Rust 工具链（Windows 下自动加载系统中文字体）。

```bash
# 开发模式运行
cargo run

# 编译优化版
cargo build --release
```

产物：`target/release/Planum.exe`，可直接双击运行。

## 📁 项目结构

```
egui-version/
├── Cargo.toml
├── icon.ico            # 应用图标（多尺寸）
├── src/
│   ├── main.rs         # UI 布局 / 交互 / 动画 / 绘制
│   ├── data.rs         # 数据层：待办、阶段计划、重点日、JSON 持久化
│   ├── lunar.rs        # 农历 / 干支 / 节气 / 节日（从 JS 版移植）
│   └── icon.rgba       # 窗口图标原始 RGBA 数据（编译期嵌入）
```

## ⌨️ 快捷键

| 键 | 功能 |
|---|---|
| `N` | 打开待办添加栏 |
| `P` | 新建阶段计划 |
| `←` / `→` | 上一月 / 下一月 |
| `T` | 回到今天 |
| `Esc` | 收起面板 / 取消编辑 |
| 双击待办 | 就地编辑该条 |

## 📝 数据说明

程序首次启动会写入示例数据，方便查看效果。数据文件位于：

```
%APPDATA%\DeskCalendarEgui\calendar-data.json
```

删除该文件即可恢复初始示例数据。

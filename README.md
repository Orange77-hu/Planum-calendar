# Planum · 计划日历

一个用 **纯 Rust + egui** 写的桌面日历 / 待办应用：本地存储、深色主题、完整中文农历、窗口记忆、导入导出，无网络请求、无需登录。

</div>

---

## ✨ 功能

### 📅 月历
- 月视图，标注农历 / 干支 / 生肖 / 二十四节气 / 节日，跨月日期自动弱化
- 当日高亮为橙色圆角方块；重点日可加星标 + 备注（鼠标悬停星标查看）
- 每个日期格上方显示当日待办数量（如 `44项`），不与其他信息重叠
- 阶段计划在日期格底部以**居中的彩色小方块**标记（最多 5 个），不遮挡两侧内容
- 计划文字按格子实际像素宽度动态截断，窗口缩小也不会溢出到相邻格子

### ✅ 待办
- 按日期查看当日待办，支持优先级（高 / 中 / 低）与完成状态，优先级文字可**点击直接切换**
- 单击选中高亮（高亮色跟随优先级 / 完成状态）、双击就地编辑
- `Enter` 保存、点击外部保存、`Esc` 取消编辑
- 选中文字加亮加粗，多行文字整体框选高亮，不遮住低 / 中 / 高重要度标签

### 📋 左侧栏
- 今日大日期 / 实时时钟 / 一天时间进度
- 本月任务统计与完成率
- 阶段计划列表（创建 / 就地编辑 / 删除，整行悬停高亮，竖三点菜单，无边框小按钮）
- 未来七天待办 + 阶段计划**合并显示**（不分开），日期粗体强调、文字整段高亮

### 📦 导入 / 导出
- 支持 **JSON**（导入 + 导出）与 **Markdown**（导出）两种格式
- 导出范围可自选：**日 / 周 / 月 / 年**
- 点击导出后弹出**原生文件管理器**选择保存位置（rfd），默认目录 `%APPDATA%/DeskCalendarEgui/exports/`
- Markdown 导出按日期分组、去掉计划 id、同一天的计划合并到一个日期标题下

### 🎛 其他
- 日期跳转：点击「跳转」按钮直接变输入框，输入日期回车跳转
- 窗口记忆：记住上次的位置 / 大小 / 最大化状态
- 主题：强制深色；系统原生标题栏用 DWM 染成主面板同色，视觉上与界面融为一体（拖拽 / 双击最大化 / 缩放等保持原生手感）
- 右键菜单：添加待办 / 标记重点日 / 回到今天 / 编辑删除阶段计划
- 月份切换淡入动画、选中脉冲等微交互

## 🛠 技术栈

| 项 | 说明 |
|---|---|
| 语言 | Rust 2021 |
| GUI | [egui](https://github.com/emilk/egui) / [eframe](https://github.com/emilk/egui/tree/master/crates/eframe) 0.29（persistence 持久化） |
| 农历 | 自研移植（1900–2100 数据表） |
| 日期时间 | chrono 0.4 |
| 序列化 | serde + serde_json |
| 原生文件对话框 | rfd 0.15 |
| 窗口句柄（DWM 标题栏染色） | raw-window-handle 0.6 |

## 🚀 构建与运行

需要 Rust 工具链（Windows 下自动加载系统中文字体，并从 Segoe UI Symbol 取竖三点字形）。

```bash
# 开发模式运行
cargo run

# 编译优化版
cargo build --release
```

产物：`target/release/Planum.exe`，可直接双击运行。也可到 [Releases](https://github.com/Orange77-hu/Planum-calendar/releases) 下载预编译包。

## 📁 项目结构

```text
egui-version/
├── Cargo.toml          # 依赖与版本
├── Cargo.lock
├── icon.ico            # 应用图标（多尺寸，任务栏固定用）
├── src/
│   ├── main.rs         # UI 布局 / 交互 / 动画 / 绘制 / 导入导出 / 窗口记忆
│   ├── data.rs         # 数据层：待办、阶段计划、重点日备注、JSON/Markdown 导入导出
│   ├── lunar.rs        # 农历 / 干支 / 节气 / 节日
│   └── icon.rgba       # 窗口图标原始 RGBA（编译期嵌入）
```

## ⌨️ 快捷键

| 键 | 功能 |
|---|---|
| `N` | 打开待办添加栏 |
| `P` | 新建阶段计划 |
| `←` / `→` | 上一月 / 下一月 |
| `T` | 回到今天 |
| `Esc` | 收起面板 / 取消编辑 |
| `Enter` | 保存当前编辑的待办 / 阶段计划 / 日期跳转 |
| 双击待办 | 就地编辑该条 |

> 编辑待办 / 阶段计划 / 日期跳转期间，`N`、`P` 与左右翻月快捷键会暂时屏蔽，避免误触。

## 📝 数据说明

全部数据本地存储，无需账号、无网络请求。首次启动写入示例数据，方便查看效果。

| 文件 | 位置 | 说明 |
|---|---|---|
| `calendar-data.json` | `%APPDATA%\DeskCalendarEgui\` | 待办 / 阶段计划 / 重点日备注 |
| `app.ron` | 同上 | egui 持久化：窗口几何 `win_geom`、主题偏好（锁定 Dark） |
| `exports\` | 同上 | 导出文件默认目录 |

删除 `calendar-data.json` 即可恢复初始示例数据。
